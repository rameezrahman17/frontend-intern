# Media Assets

Place the following files in this directory:

- `couple-video-1.mp4` — Short looping video (portrait orientation preferred)
- `couple-photo-1.jpeg` — Photo for the collage
- `our-song.mp3` — Background music file

You can add more photos (e.g. `photo-2.jpeg`, `photo-3.jpeg`) and
reference them in `lib/birthday-config.ts`.
